Recedencia was built to simplify property management tasks by organizing tenant information, monitoring payment status, and supporting ongoing records in one application. The project emphasizes clarity, structure, and efficiency for owners who need to keep track of multiple households or rental units.

I worked on the full-stack implementation, including the interface, application structure, and the core features used to manage tenants and payments. The goal was to create a system that is practical for real management tasks while still being easy to navigate.
